Value-added-CHOICE VAT notch (A2): the firm chooses value added z
========================================================================
PROFIT FUNCTIONS (choice variable z = value added; y = z/(1-delta))
------------------------------------------------------------------------
  tau = 0.20 statutory; delta = sector deductible share;
  C(z;n,e) = (n/(1+1/e))*(z/n)**(1+1/e); ability n = undistorted VA.

    Unregistered:  pi = z          - C(z;n,e)   ->  z* = n
    Registered:    pi = (1-tau)*z  - C(z;n,e)   ->  z* = n*(1-tau)**e

  Turnover is the accounting image y = z/(1-delta). The £85k notch is
  on TURNOVER, so in value-added space the threshold is sector-specific
  z_T = (1-delta)*T*.

  Notch jump          tau*z_T = tau*(1-delta)*T*  (IDENTICAL to A, B)
  Dominated (VA)      a_z = (1-delta)*T**tau/(1-tau) = (1-delta)*£21,250
  Dominated (turnover)a_y = a_z/(1-delta) = T**tau/(1-tau) = £21,250
                      delta-INDEPENDENT (matches the paper's section 4)
  Ability recovery    reg:   n = (1-delta)*y_obs/(1-tau)**e
                      unreg: n = (1-delta)*y_obs

THREE PROPERTIES A2 SECURES
------------------------------------------------------------------------
  1. A literal value-added base: the firm optimises over value added.
  2. A bounded ability n = undistorted value added; as delta->1 the
     observed value added (1-delta)y_obs -> 0 so n -> 0, NOT infinity
     (this is the key fix versus model A).
  3. The paper's headline £21,250 turnover dominated region for EVERY
     sector (section 4).

THE ONE COST
------------------------------------------------------------------------
  The single £85k notch on TURNOVER becomes a sector-specific notch on
  VALUE ADDED at z_T = (1-delta)*T*: the threshold the firm 'feels' in
  its own choice variable depends on its sector deductible share.

VERDICT
========================================================================
A2 is the CLEANEST of the three formulations for a value-added VAT base.
By letting the firm choose value added z directly it: (i) uses a literal
value-added base; (ii) recovers a BOUNDED, economically sensible ability
n = undistorted value added that goes to 0 (not infinity) as delta -> 1,
fixing model A's blow-up while keeping a clean primitive like model B;
and (iii) reproduces the paper's headline £21,250 turnover dominated
region for every sector (which B loses). The only price is that the
registration notch, expressed in the firm's value-added choice variable,
becomes sector-specific at z_T = (1-delta)*T*. On balance A2 dominates
both A (unbounded ability) and B (sector-shrinking dominated region).
